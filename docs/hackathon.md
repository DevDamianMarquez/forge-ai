# FORGE — Hackathon Context

## Event

**Meta Global AI Developer Hackathon**

FORGE was started from scratch during this hackathon. No code or design predates the event.

## Track

**Indie Developer**

## Problem Statement

**Push the Frontier**

## Scope Declaration

All functionality presented for FORGE — the OBSERVE → MODEL → HYPOTHESIZE → EXPERIMENT → VERIFY → IMPROVE workflow, the FastAPI backend, the Next.js/React frontend, the deterministic physics tools, and the integration with Meta AI technologies (Meta Model API, Muse Spark, SAM 3.1, and optionally Muse Spark Open) — will be built during the hackathon submission window.

At the time of this document's creation, this repository contains only:

- Project documentation (`README.md`, `docs/architecture.md`, this file)
- Initial, empty backend/frontend directory structure
- Baseline project configuration files (`.gitignore`, `.env.example`, `requirements.txt`)

No application logic, API integrations, or physics calculations have been implemented. Any functionality demonstrated at submission time was built within the hackathon period.

## Initial Physical Domain

Simple mechanical transmission systems: gears, shafts, RPM, torque, and basic mechanical constraints. This narrow domain was chosen to keep the hackathon build concrete and demoable within the event timeframe, while the underlying architecture (AI reasoning layer separated from deterministic physics tools) is intended to generalize to other physical domains in future work.
